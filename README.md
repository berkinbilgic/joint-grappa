# Joint GRAPPA for Phase-Cycled Balanced SSFP

MATLAB code and example data for joint GRAPPA reconstruction of phase-cycled bSSFP. `script_joint_grappa_bssfp.m` loads fully sampled bSSFP data with four phase cycles, undersamples them at R = 6, and reconstructs them with GRAPPA and Joint GRAPPA.

## Usage

Run `script_joint_grappa_bssfp.m` from the repository folder in MATLAB.

## Reference

B Bilgic, T Witzel, H Bhat, LL Wald, K Setsompop. Joint Reconstruction for Phase-Cycled Balanced SSFP. [[PDF]](https://www.martinos.org/~berkin/2016_08_06_bssfp_abstract.pdf)
